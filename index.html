Activity 2

Understanding the Agent Loop

Follow and repeat the agent loop until the goal is complete or human help is required.

20 minutes
Objective: Understand how an AI agent moves through a task by following and repeating an agent loop.
1. Goal2. Observe3. Plan4. Act5. Check6. Repeat or Finish
StageMeaning
GoalUnderstand what must be achieved.
ObserveExamine available and missing information.
PlanDecide what should happen next.
ActPerform one permitted action.
CheckCheck whether the action worked and the information is reliable.
Repeat or FinishRepeat if more work is needed, or send the result for human review.
Simple example: If an employee requests training without supervisor approval, the agent observes that the approval is missing, plans to request it, asks the employee, checks whether it was received, and repeats the loop using the new information.

  • Supervisor approval and an available departmental budget are required.
  • The AI agent can prepare a recommendation, but a human must make the final decision.

Step 3: Group Task

Using the completed canvas, create a workflow for the Professional Development Request Agent.

Scenario:
The employee provides: employee details; course title and provider; dates; cost; course outline; explanation of work relevance; and supervisor approval.

The agent should: check completeness, request missing information, retrieve the approved policy, check eligibility and budget, prepare an evidence-based recommendation, and route it to an authorized human reviewer.

The agent must not: approve or reject requests, commit funds, register employees, or delete official records.

Steps to Generate the Flowchart

  1. Start the workflow.
  2. The employee submits a professional development request.
  3. The agent collects the employee details, course information, dates, cost, course outline, work relevance, and supervisor approval.
  4. The agent checks whether all required information is complete.
  5. Decide: Is the request complete?
    1. If No, request the missing information.
    2. The employee provides the additional information.
    3. Return to the completeness check.
  6. If Yes, retrieve the approved professional development policy and required-documents checklist.
  7. Check the employee’s eligibility against the approved policy.
  8. Check the course cost and available departmental budget using an authorized system or request a human check if the system is unavailable.
  9. Identify any unmet requirements, exceptions, ambiguous information, or conflicts.
  10. Prepare an evidence-based recommendation with the supporting policy sources.
  11. Route the recommendation to an authorized human reviewer.
  12. The human reviewer examines the request, evidence, recommendation, and any exceptions.
  13. Decide: Is more information or correction required?
    1. If Yes, return the request for clarification or correction, then return to the review stage.
    2. If No, the human reviewer makes the final approval or rejection decision.
  14. Record the request, checks, evidence, recommendation, human decision, and date.
  15. End the workflow.
